# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-05-07

### Added
- Initial release of Global Asset Portfolio Analysis System
- Modular architecture with clean separation of concerns
- Support for 14 global assets across multiple asset classes
- 7 pre-configured portfolio strategies
- Comprehensive backtesting engine with 11+ performance metrics
- Professional visualization module with 10+ chart types
- Flexible configuration system
- Complete English documentation and code comments
- MIT License
- Contributing guidelines

### Features
- **Data Loading**: Robust CSV data loader with cleaning and alignment
- **Backtesting**: Full-featured backtesting engine with performance metrics
- **Visualization**: Publication-quality charts and plots
- **Metrics**: Sharpe ratio, Sortino ratio, Calmar ratio, drawdown analysis, VaR, and more
- **Portfolios**: Rate cut cycle, AI theme, China assets, global equity, balanced, equal weight, 60/40

### Documentation
- Comprehensive README with quick start guide
- API documentation in docstrings
- Contributing guidelines
- MIT License
