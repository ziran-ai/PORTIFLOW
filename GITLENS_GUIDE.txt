================================================================================
PORTIFLOW - GitLens Upload Guide
================================================================================

Step 1: Stage All Changes
--------------------------
In GitLens panel (left sidebar):
1. Click on "Source Control" icon (3rd icon from top)
2. You'll see all changed files under "Changes"
3. Click the "+" icon next to "Changes" to stage all files
   OR hover over each file and click the "+" icon

Step 2: Commit Changes
----------------------
1. In the message box at the top, type:
   "Initial commit: PORTIFLOW - Your Portfolio, Flowing Smart"
2. Click the checkmark (✓) icon or press Ctrl+Enter

Step 3: Create GitHub Repository
---------------------------------
1. Go to https://github.com/new
2. Repository name: PORTIFLOW
3. Description: Your Portfolio, Flowing Smart - A comprehensive framework for intelligent portfolio analysis
4. Choose: Public
5. DO NOT initialize with README, .gitignore, or license
6. Click "Create repository"

Step 4: Push to GitHub via GitLens
-----------------------------------
Method A - Using GitLens UI:
1. In GitLens panel, click the "..." menu (top right)
2. Select "Remote" > "Add Remote"
3. Enter remote URL: https://github.com/YOUR_USERNAME/PORTIFLOW.git
4. Name it: origin
5. Click the "..." menu again
6. Select "Push" > "Push to..."
7. Select "origin"

Method B - Using Terminal in VS Code:
1. Press Ctrl+` to open terminal
2. Run these commands:
   git remote add origin https://github.com/YOUR_USERNAME/PORTIFLOW.git
   git branch -M main
   git push -u origin main

Step 5: Verify Upload
----------------------
1. Refresh your GitHub repository page
2. You should see all files uploaded
3. README.md with the PORTIFLOW banner will be displayed

================================================================================
IMPORTANT NOTES:
================================================================================

- Replace YOUR_USERNAME with your actual GitHub username
- Make sure you're logged into GitHub in VS Code
- If prompted for credentials, use your GitHub username and Personal Access Token
- The image.png placeholder needs to be replaced with your actual banner image

================================================================================
TROUBLESHOOTING:
================================================================================

Issue: "Authentication failed"
Solution: 
1. Go to GitHub Settings > Developer settings > Personal access tokens
2. Generate new token with "repo" permissions
3. Use token as password when prompted

Issue: "Remote already exists"
Solution: Run in terminal:
git remote remove origin
Then try adding remote again

Issue: "Failed to push"
Solution: Run in terminal:
git pull origin main --rebase
git push -u origin main
